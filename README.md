# StudyBridge Agency - Template

Una plantilla profesional y completa para agencias educativas. Diseñada como template personalizable con todos los elementos necesarios.

## Características

- ✨ Diseño moderno y responsivo
- 📱 Mobile-first approach
- 🎨 Colores personalizables
- 📄 Múltiples páginas incluidas
- 🔧 Fácil de personalizar

## Páginas Incluidas

- **Inicio** - Hero con propuesta de valor
- **Servicios** - Catálogo de servicios
- **Planes** - Planes y precios
- **La Empresa** - About page
- **Blog** - Noticias y artículos
- **Testimonios** - Reseñas de clientes
- **Contacto** - Formulario de contacto

## Estructura

```
/StudyBridge Agency
├── index.html           # Página principal
├── servicios.html       # Servicios
├── planes.html          # Planes de precios
├── la-empresa.html      # Sobre la empresa
├── noticias.html        # Blog
├── resenas.html         # Testimonios
├── contacto.html        # Contacto
├── tweaks-panel.jsx     # Panel de edición
└── .gitignore          # Git ignore
```

## Cómo usar

1. Descarga la plantilla
2. Personaliza los colores, textos e imágenes
3. Reemplaza la información de contacto
4. Agrega tus servicios y precios
5. Deploya en tu servidor
